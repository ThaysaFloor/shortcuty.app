# PAPA PIZZA V5.5 — Shortcuty Studio

Projeto de conferência de estoque e produção para Apple Shortcuts, escrito em Shortcuty.

A versão atual está em [`papa-pizza/`](papa-pizza/README.md). Ela usa uma lista alfabética dos 60 produtos originais, permite pausar, retomar e revisar itens, e mantém um JSON principal e um backup por conferência.

**Build oficial concluído: 1.108 ações, 0 erros e 43 avisos. Ainda não executado no iPhone nem assinado.**

Para importar no Studio, use [`PAPA_PIZZA_V5.shortcutystudio`](papa-pizza/PAPA_PIZZA_V5.shortcutystudio). O mesmo projeto também está disponível com a extensão solicitada [`.shortcutystudio.json`](papa-pizza/PAPA_PIZZA_V5.shortcutystudio.json).

A V5.4 usa pastas preparadas manualmente. Consulte [PREPARAR_PASTAS.md](papa-pizza/PREPARAR_PASTAS.md). Ela inclui três avisos temporários para localizar a demora observada no iPhone; a correção ainda precisa de reteste.

A V5.5 corrige a preparação de data/nome e usa a referência retornada por Salvar nas atualizações. Arquivos de teste antigos `.txt` são preservados; comece o reteste por Nova conferência.
